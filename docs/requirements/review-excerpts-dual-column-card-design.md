## 1. 设计目标

双列流用于快速浏览和发现摘录。卡片保留参考图中的编辑感与奶油白纸面，并使用 iOS 透明毛玻璃承载来源信息，同时保证中文摘录在双列窄卡片中可读、状态清晰、操作不误触。

卡片本身不承担完整阅读功能。用户点击后打开居中阅读弹窗查看全文、章节、日期、“我的想法”和分享功能。

## 2. 卡片结构

```text
┌──────────────────────────┐
│ ●                    ☆   │
│                          │
│ “摘录正文最多显示五行，   │
│   超出的内容使用省略号，   │
│   不在卡片内部滚动。       │
│   保持舒适的行高。        │
│   这一行用于示意截断。”   │
│                       ▣  │
├──────────────────────────┤
│ 《书名》                 │
│ 作者                     │
└──────────────────────────┘
```

- 顶部为奶油白或暖灰纸面摘录内容区，底部为透明 iOS 毛玻璃信息区。
- 顶部内容面板略向内缩进，使外层玻璃在四周形成窄边。
- 外层卡片不使用轮廓线，以透明玻璃、柔和阴影和适度圆角建立边界。
- 不使用书封图片，避免压缩正文空间。

## 3. 双列排列

- 使用两列布局，卡片自身保持统一高度。
- 右列相对左列整体向下错开 32 点；不要求两张卡片底部齐平。
- 数据按每行左卡、右卡组织。单张数据位于左列，不额外居中。
- 卡片间距优先使用现有设计令牌。
- 手机、平板和桌面端均保持双列结构；宽屏限制内容最大宽度或增加页面留白。

## 4. 摘录内容区

- 默认最多显示 5 行，超出使用省略号；禁止卡片内部滚动。
- 真实设备测试后可以微调行数。
- 短摘录在内容区垂直居中；多行正文左对齐，不使用整段居中。
- 正文保持舒适行高，开头和结尾引号可使用朱橙色作为视觉识别。
- 正文不能因收藏、未看或笔记状态而缩减到难以阅读。
- 点击区域覆盖正文和底部来源区；收藏星标拥有独立点击区域。

## 5. 底部毛玻璃信息区

视觉层次由单色半透明玻璃 tint、背景模糊、微弱白色内高光和柔和阴影组成；不使用朱橙渐变、颗粒底色或描边。

- 浅色模式下玻璃保持足够透光，同时确保深色书名和作者清晰可读。
- 当前卡片外层玻璃与底部信息区保持连续，不增加分割描边。
- 只显示书名和作者，不显示日期、章节或其他元数据。
- 书名和作者分别限制一行，溢出使用省略号；缺少作者时只显示书名。
- 视觉层级通过字重和颜色区分，书名使用半粗体暖白色，作者使用常规字重和稍低透明度的暖白色。

## 6. 卡片状态

- 未看：左上角显示品牌强调色实心圆点。进入详情并保持可见 2 秒后写入 `viewedAt`，返回双列后圆点消失。已看状态不显示文字标签，也不降低整卡透明度。
- 收藏：右上角显示星标。未收藏为空心星，收藏后为浅金色实心星；点击区域至少 44×44 点。点击星标只切换收藏，不得展开阅读页。写入失败时恢复原状态并提示。
- 我的想法：只在内容区显示一个很小的笔记状态图标，不显示文字或正文；没有笔记时完全隐藏。图标不能挤占书名与作者。

## 7. 视觉样式

- 奶油白内容区优先复用项目纸面或暖白令牌，接近不透明；通过圆角和柔和阴影与玻璃区分，不使用轮廓线。
- iOS 玻璃通过单色透明 tint、背景模糊和微弱内高光形成，不使用线性或径向颜色渐变。
- 不增加第二个独立彩色容器；收藏、看过等状态不改变玻璃透明度与色调。
- 系统减少透明度、设备性能较低或浏览器不支持 `backdrop-filter` 时，回退为无颜色的半透明暖白面板。
- 限制同一视口同时启用模糊的卡片数量，避免滚动时持续重绘。

## 8. 字体统一规则

1. 摘录正文、《书名》和作者使用同一个字体大小。
2. 使用统一卡片字号令牌 `--feed-card-font-size`；同一断点下所有卡片及卡片内文字完全一致。
3. 不允许根据摘录长度单独缩放某张卡片字体，也不允许把作者设置成比书名更小。
4. 视觉层级通过字重和颜色区分，不通过字号区分。
5. 手机、平板和桌面端可以分别使用不同统一字号。
6. 用户调整系统字号时，卡片所有文字同步缩放。

## 9. 交互与动效

- 点击正文或来源区打开阅读弹窗；点击收藏只切换收藏。
- 键盘聚焦卡片后，Enter 或空格进入阅读页；收藏是独立可聚焦控件。
- 手机按下时可有轻微缩放或透明度变化；桌面悬停只轻微增强阴影，不上浮、不新增描边。
- 尊重 `prefers-reduced-motion`。从卡片进入阅读页时使用与内容卡片连续的展开动效。

## 10. 无障碍

- 卡片可读标签包含摘要、书名、作者及未看状态。
- 未看圆点不能只依赖颜色，读屏需要读出“未看”。
- 收藏按钮提供明确状态和 `aria-pressed`；所有交互控件有可见焦点和至少 44×44 点触控区域。
- 毛玻璃和纸面上保持足够文字对比度；支持动态字号，大字号下优先调整卡片高度和正文行数，不截断关键操作。

## 11. 边界状态

- 0 条摘录使用现有空状态；1 条只显示左卡；2 条左右各一张；3 条及以上按行组织并保持右列错层。
- 极短正文垂直居中；超过 5 行截断；书名或作者过长各自单行省略；缺少作者只显示书名。
- 没有我的想法时不显示状态；毛玻璃不可用时使用弱纹理回退；收藏失败恢复星标并提示。

## 12. 明确排除

- 双列卡片不显示添加日期、章节或“我的想法”标题/正文。
- 不增加标签或手动“已回顾”按钮。
- 不使用卡片内部滚动、书封图片或底部收藏按钮。
- 不使用任何颜色渐变或普通实色代替透明毛玻璃。
- 卡片外层、纸面和信息区均不使用深色或黑色轮廓线。

## 13. 验收标准

- 卡片自身等高，右列向下错位 32 点；正文最多 5 行并显示省略号。
- 内有奶油白纸面，外有连续透明 iOS 毛玻璃；卡片无轮廓线，并提供无模糊降级样式。
- 底部只有单行书名和单行作者，二者与摘录正文字号一致。
- 未看圆点、收藏星标和笔记图标清晰、互不冲突，收藏不会误触展开。
- 看过状态更新后圆点消失，不立即重排；卡片打开阅读弹窗并保持滚动上下文。
- 手机、平板和桌面端无文字重叠或操作区域冲突；低性能、减少透明度及无背景模糊时稳定。
